# MemeGenerator

[![License: MIT](https://img.shields.io/github/license/ysskrishna/basic-meme-generator)](https://github.com/ysskrishna/basic-meme-generator/blob/master/LICENSE) [![Author site](https://img.shields.io/badge/author-ysskrishna.space-informational)](https://ysskrishna.space)

A Simple Meme Generator using react, ImgFlip APIs

## Project setup
```
npm install
```

Note: update credentials in src\actions\secrets.js
